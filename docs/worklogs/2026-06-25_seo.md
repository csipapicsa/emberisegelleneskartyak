## Target keywords (for Phase 3 content pages)

These are the Hungarian terms worth creating real crawlable content around.
Do not put these in `<meta name="keywords">` — Google ignores that tag.
They need to appear naturally in page titles, h1/h2 headings, and body text.

| Term | Intent |
|---|---|
| online kártyajáték | broad entry point |
| vicces kártyajáték | humour-seekers |
| felnőtt kártyajáték | adult game seekers |
| online társasjáték barátokkal | social/party game intent |
| böngészős társasjáték | tech-specific (no install) |
| többjátékos kártyajáték | multiplayer intent |
| játék telefonra barátokkal | mobile-first users |
| ivós játék online | drinking game niche |
| partijáték online | party game broad |
| cards against humanity magyarul | branded, high intent |

Recommended workflow:
1. Verify search volume in Google Keyword Planner for each term
2. Pick the 3–4 with highest volume × lowest competition
3. Write one content page per term (Phase 3)
4. After 2–4 weeks, review Search Console for impressions vs CTR
5. Rewrite titles/descriptions on pages that get impressions but poor CTR

## Notes on Twitter/X and other platforms

The `twitter:card` meta tag namespace is still correct — X (formerly Twitter),
Discord, Slack, and iMessage all read `twitter:*` tags. No change needed.

Reddit, TikTok, and Instagram have no platform-specific meta tags. They read
the standard Open Graph tags, which are now present on every page.
